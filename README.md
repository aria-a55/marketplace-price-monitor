# Мониторинг цен на маркетплейсах

Программа следит за ценами на товары в интернет-магазинах и сохраняет историю цен.
Пользователь добавляет ссылку на товар и порог цены, программа проверяет текущую цену.

Магазины: Читай-город, Яндекс Маркет, Kari.

## Что сделано

- база данных SQLite: товары и история цен;
- поиск цены в json любой вложенности (один код для всех магазинов);
- общий класс парсера и парсеры магазинов;
- открытие страниц в настоящем браузере (Playwright) для сайтов, которые не отдают страницу обычному запросу;
- локальная модель Qwen3 4B (Ollama): находит цену в тексте страницы, если обычный код не справился;
- ИИ-агент: программа сама открывает страницу и ищет цену парсером, а если не нашла - Qwen читает текст страницы, находит и проверяет цену и сохраняет ее в базу;
- Telegram-бот: ссылка на товар -> агент узнает цену; список, история, порог; бот сам проверяет цены раз в час и пишет, когда цена ниже порога;
- `/history <номер>` показывает последние 15 записей и отправляет график всей истории с линией порога, если он задан;
- команды для работы из консоли.

## Установка

```
pip install -r requirements.txt
playwright install chromium
```

Для ИИ: установить Ollama (https://ollama.com) и скачать модель:

```
ollama pull qwen3:4b
```

## Telegram-бот

1. Создать бота у @BotFather и получить токен.
2. Положить токен в файл `bot_token.txt` рядом с `main.py` (файл не попадает в git).
3. Запустить:

```
python bot.py
```

Если `api.telegram.org` не открывается, в `config.py` можно указать прокси только для бота (`TELEGRAM_PROXY`), сайты магазинов при этом открываются напрямую.

## Консольные команды

```
python main.py add "https://www.chitai-gorod.ru/product/..." --threshold 1500
python main.py list
python main.py check
python main.py history 1
python main.py remove 1
python main.py agent "https://www.chitai-gorod.ru/product/..." --threshold 1500
```

## Файлы

```
main.py           команды и проверка цен
config.py         настройки
db.py             работа с базой данных
http_client.py    скачивание страниц обычным запросом
browser.py        открытие страниц в браузере
price_finder.py   поиск цены и названия в json, json из html
ai.py             запросы к локальной модели Qwen
agent.py          ИИ-агент и его инструменты
bot.py            Telegram-бот
charts.py         график истории цен для Telegram
parsers/          парсеры магазинов (base.py - общий класс)
```

Бот сообщает о падении цены на 15% и более относительно предыдущей сохранённой
цены, даже если порог не задан. При неизменной цене уведомление не повторяется.
Если одновременно достигнут порог, оба события приходят одним сообщением.
Резкие снижения отмечаются на графике. Это признак возможной распродажи.
